\# Contributing



Contributions that improve the project's reliability, documentation, and defensive detection capabilities are welcome.



\## Guidelines



1\. Keep changes focused and clearly documented.

2\. Do not collect or store actual keystrokes.

3\. Add unit tests for new behavior.

4\. Use descriptive names for functions and variables.

5\. Document known limitations and assumptions.

6\. Run the test suite before submitting changes.



\## Testing



Run the following command from the project root:



```powershell

py -m unittest discover -s tests -v

```



\## Reporting Issues



When reporting an issue, include the steps to reproduce it, the expected behavior, and the actual result. Do not include passwords, personal information, or other sensitive data.
